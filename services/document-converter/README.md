# FluxShare document conversion endpoint

This container implements the JSON endpoint used by FluxShare for DOCX to PDF, PDF merge, page extraction, content-stream compression, page rotation, OCR-to-text, and FFmpeg audio/video conversion. The `Dockerfile.vercel` image is designed for the connected Vercel `fluxshare-converter` container project. It includes LibreOffice, FFmpeg, Poppler, and English Tesseract data. Set `ALLOWED_ORIGINS` to the exact FluxShare site origins, comma separated, and set `LIBREOFFICE_URL` to the public HTTPS `/convert` endpoint in the FluxShare app and release workflows. Cloud Run remains an alternative when independent hosting or request-size limits require it.

Requests and responses use base64 JSON. Individual input files and outputs are capped at 50 MB; JSON requests are capped at 75 MB, so PDF merge input must fit within that aggregate request cap. DOCX conversion has a 90-second timeout, media conversion has a 120-second timeout, OCR is limited to 20 pages, and other PDF tools are limited to 200 pages. The service applies a best-effort in-process limit of 20 conversion requests per client IP per minute. This limit is per process and is not a substitute for platform-level rate limiting. Restrict origins, service ingress, and request quotas at the hosting layer before exposing it publicly. For authenticated/private uploads, put an auth-aware API gateway in front of this service. Document and media files are uploaded to the converter for processing.

Build locally with `docker build -t fluxshare-converter -f services/document-converter/Dockerfile.vercel services/document-converter` and run with `docker run -p 8080:8080 -e ALLOWED_ORIGINS=https://fluxshare-lac.vercel.app fluxshare-converter`. The health check is `/health`. Vercel's current Dockerfile support runs HTTP containers on Fluid compute; validate representative upload sizes and durations against the account plan before public launch. The app sends base64 JSON, so provider request and response limits can be lower than the service's 50 MB internal file cap.

For Cloud Run fallback in Mumbai, install and authenticate the Google Cloud CLI, select a project with billing and Cloud Build/Artifact Registry/Cloud Run APIs enabled, set `FLUXSHARE_ALLOWED_ORIGINS` to the exact public and preview app origins, then run `bash deploy_cloud_run.sh` from this directory. The script caps Cloud Run at three instances and one request per instance at a time. Set the resulting HTTPS `/convert` endpoint as `LIBREOFFICE_URL` in Vercel and the Windows and Android release workflows.

PDF compression rewrites the PDF and compresses page content streams. It cannot recompress embedded images and may not reduce every file's size.
